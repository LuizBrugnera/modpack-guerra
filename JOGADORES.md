# Modpack Guerra — guia rápido para jogadores

1. **Instale o Prism Launcher** (https://prismlauncher.org) e o **Java 21** (o Prism pode baixar o Java sozinho em *Configurações → Java → Baixar Java*).
2. **Importe a instância**: no Prism, *Adicionar instância → Importar* e escolha o arquivo `ModpackGuerra-Prism.zip` que o admin mandou. Ela já vem com o packwiz-installer: toda vez que você abrir o jogo, os mods são atualizados sozinhos.
   - Alternativa: importar o `.mrpack` no Modrinth App. Nesse caso, a cada atualização do pack você precisa importar de novo.
3. **Memória**: clique com o direito na instância → *Editar → Configurações → Java* e coloque **8 GB** de memória máxima (mínimo 6 GB).
4. **Entrar no servidor**: *Multijogador → Adicionar servidor* → endereço `<ip-ou-dominio>:25565`. Você precisa estar na whitelist (peça ao admin).
5. **Voice chat**: aperte **V** no jogo para abrir o Simple Voice Chat e configurar o microfone. Use os grupos de voz do seu time.
6. **Teclas**: Create Aeronautics, TaCZ e o voice chat adicionam muitos atalhos. Revise em *Opções → Controles* e resolva os que aparecerem em vermelho.
7. **PC fraco**: desligue os shaders (Iris, *Opções → Pacotes de shaders*) e reduza o alcance do Distant Horizons.
8. **Deu problema?** Mande o arquivo `logs/latest.log` da instância para o admin (no Prism: botão *Pasta* → `minecraft/logs`).

## Regras do servidor (resumo)
- Explosões só destroem blocos no **horário de guerra**: sexta e sábado, 20h–23h (horário de Brasília). Fora disso elas ainda ferem, mas não quebram nada.
- Armas nucleares não são craftáveis: só aparecem em eventos.
- Blocos à prova total de explosão têm limite por jogador.
